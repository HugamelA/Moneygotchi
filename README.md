# Манигочи — игровой сервис финансовой грамотности для детей 7–11 лет

Функциональный прототип мобильного приложения для Android, разработанный в рамках конкурсного задания «Питомец Финни» (заказчик — Департамент финансов города Москвы).

Ребёнок заводит виртуального питомца, получает игровые монеты, распределяет их по конвертам «Обязательное», «Необязательное» и «Копилка», покупает товары для питомца, копит на финансовую цель и решает задания по финансовой грамотности. Состояние и рост питомца зависят от совокупности финансовых решений за несколько игровых дней.

Приложение не использует реальные деньги, рекламу, внутриигровые покупки и сеть, не запрашивает разрешений Android и не собирает персональные данные.

## Быстрый запуск

Требования к окружению: Android Studio (актуальная стабильная версия), JDK 17 или новее, Android SDK с платформой API 37.

1. Клонировать репозиторий:
   ```
   git clone https://github.com/HugamelA/Moneygotchi.git
   ```
2. Открыть корневую папку проекта в Android Studio и дождаться синхронизации Gradle.
3. Подключить Android-устройство (Android 8.0+) или запустить эмулятор и выполнить **Run ▶ app**.

Сборка отладочного APK из командной строки:

```
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

> Подписанная релизная сборка и инструкция по её получению будут добавлены к финальной сдаче (раздел 3.3 ТЗ).

## Демонстрационный сценарий

Игровой период в приложении — **игровой день**. День завершается нажатием на кровать в комнате, поэтому смена периодов не привязана к реальному времени: пять и более периодов проходятся подряд за несколько минут.

Для экспертной проверки предусмотрен служебный экран (режим разработчика). Путь: **⚙ Настройки → Для родителей → ответ на контрольный вопрос → нажатие на пустую область в нижней части экрана**. На служебном экране можно:

- добавить игровые дни (+1 / +7), чтобы сразу открыть все задания;
- изменить баланс, сытость, настроение, уровень и число звёзд;
- сменить вид и окрас питомца;
- сбросить задания и прогресс.

Игровые события в первые дни следуют фиксированному демонстрационному расписанию (дни 2, 4, 6, 8, 10), что обеспечивает воспроизводимость показа.

Сброс профиля: **⚙ Настройки → Удаление питомца** (с подтверждением).

## Реализованные требования (кратко)

Реализовано: первый запуск с обучением и возможностью повторить его; гостевой режим без регистрации; настройка питомца (3 вида × 3 окраса = 9 комбинаций) и ввод имени; главный экран с балансом, накоплениями, целью, показателями сытости и настроения; игровой доход с указанием источника; распределение монет по трём конвертам с контролем остатка; магазин (более 8 позиций обязательных и необязательных расходов) с ценой, категорией и влиянием на питомца; запрет покупки при нехватке средств с объяснением; 3 финансовые цели с копилкой и прогрессом; 6 заданий по 3 темам с объяснением после любого ответа; игровые события с выбором; 3 стадии развития питомца; раздел для взрослого за контрольным вопросом; сохранение прогресса между запусками.

В работе: сравнение плана бюджета с фактом по итогам дня, изменение плана до подтверждения, справочный раздел с терминами, история покупок и итоги периода, полноценный демонстрационный режим с тестовым профилем, автоматизированные тесты.

Полная таблица со статусами и планом до финала — в [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md).

## Данные и разрешения

Приложение не запрашивает ни одного разрешения Android и не обращается к сети. Все данные (имя питомца, баланс, накопления, прогресс) хранятся только на устройстве и удаляются при сбросе профиля. Имя, телефон и e-mail ребёнка или родителя не запрашиваются.
